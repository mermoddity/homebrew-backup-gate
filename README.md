# Homebrew tap for backup-gate

[backup-gate](https://github.com/mermoddity/backup-gate): Time Machine backups that pause
when macOS persistence points change, until you approve them.

```sh
brew install mermoddity/backup-gate/backup-gate
```

Homebrew only downloads the files. To install, follow the instructions it prints, or see
[Install](https://github.com/mermoddity/backup-gate#install) in the README.

The formula is copied from the matching [release](https://github.com/mermoddity/backup-gate/releases),
where its checksum and build provenance can be verified.
